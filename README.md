# 中国大陆版 AEO/GEO 营销落地页

这是面向牙科医院与医美机构的 AI 搜索前排增长落地页第一版，使用 React + Vite 构建。核心服务表达是：帮助机构进入豆包、Kimi、DeepSeek 的 AI 搜索前几个结果或推荐候选；页面、FAQ、实体信号和内容结构只是实现排名与推荐位的手段。

## 本地运行

```bash
npm install
npm run dev
```

打开终端显示的本地地址，默认通常是：

```text
http://localhost:5173/
```

## 生产构建

```bash
npm run build
npm run preview
```

## 已包含内容

- Hero 首屏与 AI 搜索前排结果演示
- 痛点、AI 搜索趋势、传统 SEO 与 AEO/GEO 对比
- 牙科医院与医美机构的用户决策路径、常见问题、前排机会和转化漏斗
- 服务内容、优势、实施流程
- AI 前排结果诊断、竞争分析、排名布点与月度追踪表达
- ¥100,000 / 年 AI 搜索前排订阅方案，列明年度交付内容与合作边界
- 明确标注的匿名示例反馈
- FAQ 手风琴
- 移动端菜单、滚动锚点、微信咨询弹窗、微信号复制
- 响应式桌面与移动端布局
